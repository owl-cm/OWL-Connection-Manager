Documentation

OWL is a professional-grade connection manager designed for system administrators and power users. It provides a unified, secure, and aesthetically superior environment for managing remote infrastructure across multiple protocols.

This documentation covers OWL's security model, SSH tooling, Docker explorer, OWL Sage AI copilot, and day-to-day workflows. Whether you manage one server or a multi-environment fleet, OWL is built to keep credentials local and operations fast.

Visual identity

OWL’s UI uses a dark purple glass theme (#0a0614 base, violet accents #a78bfa / #7c3aed). This documentation site follows the same palette.

Installation

OWL is natively optimized for Linux distributions. Follow the instructions below to deploy OWL on your workstation.

Debian-based Distributions (.deb)

The recommended way to install OWL on Ubuntu, Debian, or Linux Mint is via the official package. You can download the latest stable release from here.

Once downloaded, execute the following commands in your terminal:

sudo dpkg -i owl-connection-manager_*.deb
sudo apt-get install -f # To resolve any missing dependencies

Building from Source

For developers or users on other distributions, OWL can be compiled from source. Ensure you have Node.js (v16+) and npm installed.

# Clone the repository
git clone https://github.com/owl-cm/OWL-Connection-Manager.git

# Navigate to the directory
cd OWL-Connection-Manager

# Install dependencies
npm install

# Launch the application
npm start

Security Architecture

Security is the core pillar of OWL. The application is designed with a zero-trust approach to credential management, ensuring that your sensitive data never leaves your local machine.

The Secure Vault

All connection metadata, including passwords, private key paths, and passphrases, is stored in a local JSON vault. This vault is encrypted using AES-256-GCM (Galois/Counter Mode), providing both confidentiality and authenticity. OWL Sage settings are stored in a separate encrypted file under the same vault key.

Master Password & Key Derivation

Upon initial launch, you are required to establish a Master Password. OWL uses the PBKDF2 (Password-Based Key Derivation Function 2) algorithm with 100,000 iterations and a unique salt to derive the encryption key.

Important: OWL does not store your Master Password. If lost, the encrypted vault cannot be recovered unless you reset the vault (which permanently deletes stored data).

Session Auto-Lock

To protect against unauthorized physical access, OWL includes a configurable inactivity timer in Preferences. When triggered, the application securely clears the encryption key from memory and returns to the lock screen, requiring the Master Password to resume operations.

Vault Reset

On the unlock screen, Reset vault (deletes all data) permanently removes the encrypted connections vault and Sage configuration from local storage, then walks you through creating a new master password. This cannot be undone—export a backup first if you need to keep your connections.

Connection Management

OWL features a hierarchical management system that lets you organize large inventories of servers and jump hosts.

Hierarchical Organization & Labels

Connections can be organized into nested folders, allowing you to mirror your infrastructure's logical layout (e.g., Region > Environment > Service).

Use Color Labels on folders to categorize by importance or environment (e.g., Red for Production, Green for Development). Labels provide visual cues in the connection tree.

Smart Cloning

Smart Cloning duplicates an existing connection (including advanced SSH options and bastion fields) into the same parent folder, which is useful when provisioning similar hosts.

Advanced SSH Options

When creating or editing an SSH connection, expand Advanced SSH Options to enable popular OpenSSH -o settings. Presets ship disabled by default and include keepalives, connect timeout, compression, agent forwarding, host-key policy, and authentication preferences. You can:

  • Toggle individual options on or off
  • Edit option values before enabling
  • Add custom option names and values

Enabled options are passed to the OpenSSH CLI when opening a terminal. Select keepalive and timeout options are also mapped into the ssh2 client used for SFTP and Docker tools.

Terminal & Remote Protocols

OWL provides a high-performance terminal experience and integrated support for graphical remote access.

High-Performance SSH

Built on xterm.js and node-pty, the SSH terminal supports:

  • True Color (24-bit) support for modern CLI tools.
  • Full Mouse Integration for applications like htop, vim, and tmux.
  • Automated Authentication: Seamless handling of password and passphrase prompts, plus automatic acceptance of new host fingerprints when prompted.

RDP & VNC Support

Beyond the terminal, OWL integrates RDP (Remote Desktop Protocol) and VNC support, allowing you to manage Windows and graphical Linux environments from the same unified interface.

Broadcast Mode (Multi-Exec)

Broadcast Mode allows you to synchronize input across selected active terminal sessions. Commands typed in the primary session are sent to all chosen hosts—ideal for fleet-wide updates or checks.

Bastion & Jump Host Integration

OWL simplifies access to private networks through integrated ProxyJump support. You can configure a Bastion host as a gateway, and OWL will automatically handle the multi-hop SSH path transparently for terminals and remote tools.

SFTP File Explorer

The integrated SFTP explorer provides a graphical interface for remote file management without leaving OWL.

  • Drag-and-Drop: Upload files by dragging them from your local file manager.
  • Directory Insights: Calculate remote directory sizes using optimized background processes.
  • Breadcrumb Navigation: Navigate complex remote filesystems with an interactive path bar.

Real-Time Monitoring & Insights

Gain visibility into host health without running manual commands for every check.

Metrics Dashboard

OWL streams live telemetry from connected hosts for:

  • CPU utilization
  • Memory usage
  • Disk capacity

Docker Explorer

For SSH hosts with Docker available, the Docker Explorer lists containers, images, and volumes. You can inspect resources, run common container actions (start/stop/restart/remove), and stream live container logs from the dock without switching tools.

OWL Sage AI Copilot

OWL Sage is an optional AI assistant embedded in the workspace. Configure it under Preferences, then open it from the dock or with Ctrl+Shift+I.

Providers

Sage supports multiple providers:

  • LiteLLM — any OpenAI-compatible gateway (custom base URL)
  • OpenAI
  • Anthropic
  • Google Gemini

API keys are stored encrypted in your vault. Optional redaction strips secrets from context before they are sent to the provider.

Context tools

  • Selection — attach highlighted terminal text
  • Terminal — attach recent buffer output
  • Diagnose — snapshot metrics, top processes, Docker status, and recent lines

Suggested shell commands can be copied or run in the active terminal after confirmation.

Advanced Management Features

Command Palette

The Command Palette (Ctrl+Shift+P) provides a searchable, keyboard-driven interface for snippets and quick actions.

Command Snippets

Save frequently used commands or scripts as Snippets and run them with a click or via the palette.

Advanced Session Logging

OWL can automatically record terminal sessions. The Log Viewer supports:

  • Timeframe Filtering — locate logs by date range
  • Full-Text Search — search across log content
  • Log Rotation — remove oldest logs when total size exceeds your Preferences limit

Encrypted Backups

Export your connections into a password-protected backup and import them on another machine. Prefer a backup before resetting the vault.
